# 长篇小说大纲（Outline）

大纲是**因果链**，不是事件清单。每一章都必须改变某个东西：局势、关系、认知或代价。

## 先读

`novel.config.json` → `story/premise.md` → `story/characters/index.md` → `story/world/` → 已有 `story/outline/`。

## 工作流

1. **定卷**：卷数 = 目标字数 ÷（卷字数）。每卷写清：卷目标、卷末必须发生的变化、卷末代价、与主线的推进关系。
2. **定幕**：每卷 3 幕（建置 / 对抗 / 解决），或四幕（加“中点反转”）。标注：激励事件、第一转折、中点、至暗时刻、高潮、余韵。
3. **定节拍**：每卷 8–12 个节拍，一个节拍 = 一次不可逆的变化。节拍用“因为……所以……”写，检验因果。
4. **定章**：每章一行，字段见下表。章末钩子必须具体到“读者想知道什么”。
5. **节奏检查**：
   - 每 3–5 章一个小高潮；每卷至少一次大转折、一次真实代价。
   - 信息节奏：每章给一个新信息，同时藏住一个旧答案。
   - 连续三章同类型（打斗/对话/赶路）必须拆开。
   - 主角不能连续两章被动挨打。
6. **伏笔**：大纲阶段就标注“埋设章 / 回收章 / 回收方式”，写入 `story/foreshadowing.md`。埋了不回收的，删掉或降级为氛围细节。
7. **落盘**：`story/outline/volume-01.md`（每卷一文件），全书总表 `story/outline/book.md`，节拍表 `story/notes/beat-sheet.md`。
8. **验收**：过一遍下方清单，把不通过项直接改掉再交付。

## 章节表格式

| 章 | 暂定标题 | 视角 | 地点/时间 | 章目标 | 冲突 | 转折 | 章末钩子 | 预估字数 | 伏笔动作 |
|---|---|---|---|---|---|---|---|---|---|
| 001 |  |  |  |  |  |  |  | 2500 | 埋： |

## 大纲验收清单

1. 主角每一章都有主动选择吗？
2. 任意抽掉一章，后面会崩吗？不会就合并或删。
3. 反派有自己的完整计划吗？他的每一步是否让主角更难受？
4. 中点是否把“目标”或“代价”升级了一次？
5. 至暗时刻是否剥夺了主角最依赖的东西？
6. 高潮的解决方式是否在前文埋过伏笔（不能天降）？
7. 每卷结尾，主角的状态是否与卷首不同？
8. 感情线是否改变了主线决策，而不只是插曲？
9. 配角是否有至少一次独立行动影响主线？
10. 伏笔表里的每一项都有回收章吗？

## 反模式

- 流水账：一章一个事件，事件之间没有因果。
- 同构章节：每章都是“遇险—打赢—升级”。
- 主角被动：所有转折都由反派或巧合推动。
- 大纲写到 50 章还没有中点。
- 把“设定说明”当成剧情推进。
